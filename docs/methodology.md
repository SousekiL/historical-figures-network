# 方法论（Methodology）

本文说明数据管线、筛选口径与已知局限，保证数据可复现、可追溯。

## 1. 数据源

- **CBDB**（中国历代人物传记资料库），SQLite 数据库 `cbdb202409.db`（2024-09 版）。
- 主要用表：`BIOG_MAIN`（人物主表）、`ASSOC_DATA`（社交关系）、`ASSOC_CODES` + `ASSOC_CODE_TYPE_REL` + `ASSOC_TYPES`（关系类型）、`KIN_DATA` + `KINSHIP_CODES`（亲属关系）、`ALTNAME_DATA`（字 / 号）、`TEXT_CODES`（史料出处）、`DYNASTIES`（朝代）。

## 2. 朝代档位（8 档）

将 CBDB 的 `c_dy` 朝代代码聚合为 8 档（字典见 `data/dictionaries/dynasty_tiers.json`）：

| 档位 | CBDB `c_dy` 代码 |
|------|------------------|
| 春秋战国 | 1（漢前） |
| 秦汉 | 2, 61, 83, 29, 46, 25（秦漢及贏秦/漢/西漢/新/東漢） |
| 魏晋南北朝 | 3, 26, 53, 42, 82, 23, 27, 4, 28, 32, 44, 37, 24, 30, 41, 40, 35, 31, 68 |
| 隋唐 | 5, 6, 77（隋/唐/武周） |
| 宋 | 15 |
| 元 | 18 |
| 明 | 19, 80（明/南明） |
| 清 | 20 |

人物档位取其 `c_dy` 所属档位；一人跨多朝时以 CBDB 标注的 `c_dy` 为准（如曹操 CBDB 标为東漢，故归「秦汉」）。

## 3. 名人筛选

知名度信号 = **社交关系度**（`ASSOC_DATA` 中该人物去重后的关联人物数），按档位取 top-K（每档配额见脚本 `QUOTAS`）。

- 社交关系度为主信号：知名人物往往留下更多可考的师友 / 同僚 / 唱和 / 政敌等社会关系记录。
- 亲属关系度（`KIN_DATA`）仅作同分 tiebreaker：亲属数据多为族谱自动生成，不宜单独作为知名度依据。
- 无任何社交关系记录者不入选（避免族谱节点混入）。

## 4. 关系提取与去重

- 仅保留两端都在入选集合内的关系（保证网络连通、边有意义）。
- CBDB 中每条社交关系双向各存一条（ego / alter），构建时按 `(min(person1,person2), 关系代码, 出处)` 去重，边无方向。
- 社交关系（`ASSOC_DATA`）与亲属关系（`KIN_DATA`）合并，去重键含关系来源。

## 5. 关系类型映射

`ASSOC_DATA.c_assoc_code` → `ASSOC_CODE_TYPE_REL` → `ASSOC_TYPES` 得到层次化类型，再映射为 7 类简化关系（`type` 字段），原始描述保留在 `subtype`：

| 简化类型 | 来源（`ASSOC_TYPES`） | 说明 |
|----------|------------------------|------|
| 師生 | 0202 | 师生 / 问学 |
| 好友 | 0301 | 朋友关系 |
| 家族 | 0901 + `KIN_DATA` | 亲属关系 |
| 同僚 | 0402–0406 | 官场（平级/上下级）、政治奥援、荐举 |
| 政敵 | 0407 | 政治对抗 |
| 唱和 | 0207、05xx | 文学艺术交往、著述（赠诗、序跋、墓志等） |
| 交往 | 01xx、06xx、08xx、10xx 及未细分 | 一般社会交往、学术、军事、宗教、财务等 |

## 6. 人物类别推断

由该人物在入选网络内**主要社会关系类型**（排除「家族」）映射而来：唱和→文學家、師生→學者、好友→文人、同僚/政敵→政治家、仅亲属→名門士族、其他→文化名人。此类别为**推断值**，非人工标注，仅作参考。

## 7. 可追溯性

- 人物：保留 CBDB 人物 ID（`id` 字段）。
- 关系：保留史料出处 `source_text`（`TEXT_CODES.c_title_chn`）与 `source_pages`（页码），如《唐五代人交往詩索引》《宋人傳記資料索引(電子版)》。

## 8. 已知局限

1. **覆盖不均**：CBDB 社交关系在唐 / 宋 / 元 / 明 / 清较丰富，先秦 / 秦汉 / 魏晋南北朝较薄（传世史料少），故早期朝代人数少。
2. **「唱和」占比高**：唐宋部分大量关系来自诗文交往类索引（《唐五代人交往詩索引》《宋人傳記資料索引》），故边类型以「唱和」为主。
3. **类别为推断值**：不构成权威的「职业/身份」标签。
4. **朝代归属以 CBDB `c_dy` 为准**：跨朝人物（如曹操）按 CBDB 标注归类。
